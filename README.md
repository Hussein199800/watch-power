## التشغيل والتحقق

```sh
npm ci
npm test
npm run test:e2e
npm run sync
cd android
./gradlew testDebugUnitTest lintDebug assembleDebug
```

اختبارات الواجهة تستخدم Playwright وChromium (يمكن تحديد `CHROMIUM_PATH`). عند غياب المتصفح: `npx playwright install --with-deps chromium`. بناء أندرويد يحتاج Java 21 وSDK 36.

## المختبر

- **المزيد ← حاسبة الأحمال**: محاكاة جهاز على الحمل الحالي. الاختيار «الجهاز يعمل الآن» يجعل الزيادة صفراً. الأرقام العربية مدعومة. تُحسب طاقة الجهاز وهامش القدرة الفعلية، وأثر البطارية فقط في وضع البطارية مع بيانات القدرة والشحن والسعة والجهد المقنّن. تفترض كفاءة 90% وثبات الظروف؛ لا تشمل قدرة الإقلاع أو VA.
- **التقارير ← التقرير اليومي**: شريط إعادة المشاهدة يغير مخطط تدفق الطاقة حسب القراءة المسجلة السابقة داخل مقطع متصل. يُذكر وقت القراءة صراحة، دون استيفاء أو تمديد خلال فجوة أكبر من 20 دقيقة أو خارج السجل. الضغط على التنبيه المحلي ينقل إلى وقت رصده؛ قد يقع التنبيه داخل فجوة وتظل فارغة. السجلات القديمة بلا هوية جهاز لا تُنسب افتراضياً إلى جهاز.
- **أولوية مصدر الطاقة ← الإدارة الذكية**: خيار التجربة مفعّل افتراضياً. يفحص Kotlin القراءة ويُسجل القرار أو سبب عدم اتخاذه، ويعود قبل `api.send` أو التحقق. إلغاء التجربة والحفظ يسمح بالتنفيذ الحقيقي. الجدولة مستقلة عن خيار التجربة الذكية.
- الصلاحية تُعاد بعد فشل الاتصال وكل ثانية أثناء فتح التطبيق. الوقت المفقود/غير الصالح/المستقبلي بأكثر من دقيقة يمنع التقدير الحي. الرسوم تستخدم مللي ثانية على محور خطي، وتفصل البيانات المفقودة والفجوات الأكبر من 20 دقيقة.

## APK والتحديثات

[تحميل APK التجريبي 1.0.0](https://github.com/Hussein199800/watch-power/releases/download/lab-1.0.0-b4ed75d/watch-power-lab-debug.apk) · [الإصدارات](https://github.com/Hussein199800/watch-power/releases) · [نتائج الاختبار وحدوده](VALIDATION.md). يبني GitHub Actions الاختبارات والواجهة ومحرك Kotlin وLint ثم APK تجريبياً ويُنشر كإصدار أولي مرتبط بالتزامه مع SHA-256.

التحميل داخل التطبيق محصور بإصدارات `watch-power` في JavaScript وKotlin، مع التحقق من هوية الحزمة ورقم الإصدار والتوقيع. ملفات Debug التجريبية ليست قناة إنتاجية؛ مفتاح Debug على مشغّل Actions غير دائم. يجب إعداد توقيع دائم خاص بهذا التطبيق وإصدار موقّع قبل الاعتماد على تحديثات متتابعة. لا تُستخدم مفاتيح Car أو أسراره.
